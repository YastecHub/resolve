# @resolve/api-client

Typed API client and TanStack Query hooks for the resolve API, generated by [Orval](https://orval.dev) from the API's OpenAPI document. The dashboard imports everything it needs from here.

```
pnpm api:generate
```

That exports `apps/api/openapi.json` from the NestJS app, then regenerates `src/generated`. Never edit `src/generated` by hand; change the DTOs or decorators in the API and regenerate. CI fails if the committed client is out of date.

| File              | What it is                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| `orval.config.ts` | Generator config: react-query hooks, fetch, one file per tag                                           |
| `src/fetcher.ts`  | The fetch wrapper every generated call goes through. Throws `ApiError` built from the failure envelope |
| `src/errors.ts`   | `ApiError` with `status`, `code`, `message`, `fieldErrors`, `details`, `requestId`                     |
| `src/generated/`  | Generated endpoints and models                                                                         |

Every response keeps the API envelope, so a hook's `data` is `{ success, data, meta }`:

```ts
import { useGetHealth } from '@resolve/api-client';

const health = useGetHealth();
health.data?.data.status;
```
